## 环境限制

- 138 项后端测试因当前进程没有配置 `ASSETGRAPH_TEST_DATABASE_URL` 而按既有条件跳过，主要是 PostgreSQL 集成、迁移、并发租约与恢复类验证。本轮新增的概览和项目摘要 API 契约使用依赖覆盖完成隔离验证，已实际运行。
- 生产构建的单个 JavaScript 包约 1.13 MB（gzip 约 328 KB），Vite 给出大于 500 KB 的性能提醒。当前不影响功能，后续可按一级路由动态拆包。
- 真实录屏解析、真实麦兔草稿写入和真实业务数据的逐页视觉状态仍需要对应本地数据、账号和 Worker；本轮截图使用可控业务夹具，不据此宣称第三方现场已验收。
