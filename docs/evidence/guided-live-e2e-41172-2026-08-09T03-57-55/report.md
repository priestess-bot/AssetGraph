## 6. 测试中修复的强阻断

1. 修复知识推荐异步响应字段不匹配，素材与知识推荐可以从前端正常读取。
2. 修复工作流节点初始标签、当前修订读取和数据库字典行兼容问题。
3. 修复分镜队列时间序列化、任务排序、单场景策略绑定及基础计划回退问题。
4. 修复麦兔公开指纹被误判为密钥，同时要求所有豁免的协议公开哈希必须是严格的小写 64 位 SHA-256，阻止利用公开字段持久化任意凭据。
5. 允许已下载且权利有效的麦兔绑定素材参与本地成片，同时继续阻止无本地文件或权利不完整的素材。
6. 修复时间线“字幕”编辑未更新配音输入，并将控件明确为“配音与字幕”。
7. 删除无鉴权的本地审批旁路；交付页通过仅存于页面内存的审核凭据调用原有受保护控制面接口，审核人由服务端身份决定。
8. 修复交付包下载时 `datetime` / `UUID` 未编码导致的 500，并补充附件文件名。
9. 修复发布候选素材权利匹配优先级，避免显式本地素材编号被旧兼容别名污染。
10. 直播草稿创建发布候选时重新查询并锁定当前素材目录；撤权、受限、删除或缺失素材全部失败关闭，权利快照、发布清单及计划关联在同一事务中提交，不再只信任旧 BuildPlan 快照。
11. 麦兔任务成功但最终同步遇到瞬时错误时继续自动重试，并在前端显示“执行结果暂未同步”。
12. Windows 启动器在未配置控制面审核凭据时生成进程级临时凭据并复制到剪贴板，不写入磁盘。
13. 为上述行为补充后端、前端、脚本和安全负向回归测试。
