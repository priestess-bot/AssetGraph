# AssetGraph 当前流程状态盘点

日期：2026-07-29

适用范围：客户体验优先 v1（Release A、Release B）

权威清单：[客户体验 v1 落地 Checklist](../plans/2026-07-26-customer-experience-v1-implementation-checklist.md)

## 结论

当前项目已经形成“本地可演示、可验收”的 Release A/B 闭环，但还没有达到“真实客户数据、真实麦兔账号、真实运营用户验证过”的生产可用状态。

本文中的“已确认跑通”分为两类：

- **真实本地/脱敏样例已验收**：已经产生真实产物、截图或可回读记录。
- **自动化/种子验收已验证**：代码、API 和 UI 流程已跑通，但还没有用客户真实输入确认质量。

自动化测试通过不等于外部平台能力已可用；麦兔能力必须以当前账号 canary、变更后回读和契约指纹为准。

## 1. 已确认跑通的流程

### 1.1 真实本地或脱敏样例

#### 素材管理、约束与选材

- 扫描并导入当前本地素材。
- 图片、视频预览和素材列表展示。
- 设置媒体类型、素材用途和可执行能力。
- 设置位置、尺寸、等比、顶层/底层和桌面区域关系。
- 创建素材组、素材包和素材缺口。
- 在直播间配置中分别选择素材组和零散素材。
- 当前本地素材已确认 63 份可预览；导入报告见 `../asset-numbering/import_report_20260729_current_local_materials.json`。

#### 本地成片生产

- 从已确认内容项目生成成片分支。
- 生成时间轴、字幕、音频和配音。
- 生成 MP4、封面、字幕文件、Manifest 和质量检查结果。
- 编辑时间轴并生成新的不可变修订。
- 使用相同输入和工具版本复现相同时间轴及 Manifest 指纹。
- 已实际生成可播放的竖屏 MP4，双分支记录见 `customer-v1-v1-0515-dual-branch.json`。

#### 运营数据与归因

- 导入 CSV/XLSX 运营文件。
- 检查字段、单位、时区、重复行和错误行。
- 将场次绑定到内容版本或成片。
- 使用显式 TimeMapping 对齐场景和时间轴。
- 查看场次、内容段、模板和素材四个维度的描述性统计。
- 修改映射并生成新的归因版本，保留原始文件和历史结果。
- 脱敏文件端到端记录见 `customer-v1-v1-0608-operations.json`。

#### 知识链路与效果再生产

- 在 PostgreSQL 中建立内容、素材、事实、模板、场景、交付和效果来源链。
- 按商品、主题、模板和素材查询来源链。
- 展示约束匹配、内容相关性和效果信号的建议理由。
- 从效果观察创建新的内容项目和生产草稿。
- 保留原项目、效果证据和人工选择记录。
- 效果再生产记录见 `customer-v1-v1-0708-effect-reproduction.json`。

#### 本地交付管理

- 运行交付检查。
- 人工批准或退回交付内容。
- 生成和下载本地交付包。
- 查看交付历史。
- 撤回交付内容并保留历史记录。

### 1.2 自动化或种子验收已验证

#### 录屏到内容模板

- 本地录屏上传、校验和解析进度。
- ASR、OCR、画面片段和时间对齐结果。
- 文本清洗、敏感信息处理、片段合并。
- 单来源直播间模板约束。
- 模板审核、发布、停用和新版本。

#### 事实到直播间方案

- 商品事实卡草稿、批准、驳回和新版本。
- DesignBrief 及目标、主题、故事、详细设计输入。
- 主模板和次模板选择。
- StoryBrief、剧本块、节目段和 ShotList。
- `MaituSceneBlueprint`、Layer 和 BuildPlan。
- 场景、图层、素材、位置、层级和话术编辑。
- 方案复制到新的空白房间。

#### 麦兔安全降级

- 写入前校验目标房间 ID、标题、空白状态和未开播状态。
- 执行后的现场回读和差异展示。
- 能力不可用时生成完整人工操作清单。

以上三组流程已经通过 API/UI/worker 契约和种子验收，但不代表真实麦兔写入或真实客户内容质量已确认。

## 2. 尚未确认跑通的流程

### 2.1 外部麦兔能力

- 当前真实账号的只读 canary、房间状态读取和适配器契约指纹。
- 使用真实素材、数字人和音色进行上传或引用。
- 创建场景、插入图层、设置矩形和层级、写入话术。
- 在真实空白房间完成一次完整草稿 canary，并保存前后截图、回读和回滚记录。
- 对应 Checklist：`V1-0107`、`V1-0108`、`V1-0502`、`V1-0503`、`V1-0506`。

当前确认的是安全校验和人工降级，不是麦兔自动写入。

### 2.2 客户真实输入

- 使用客户批准的真实录屏完成“上传到可选模板”的完整验收。
- 使用客户批准的真实商品事实、目标和设计完成“事实到直播间方案”的完整验收。
- 对应 Checklist：`V1-0308`、`V1-0412`。

### 2.3 真实运营用户体验

- 新运营用户在不看说明文档的情况下完成五项任务。
- 记录成功率、耗时、错误次数、回退次数和工程师介入点。
- 产品与实际运营用户完成最终 Release A/B 验收。
- 对应 Checklist：`V1-0803`、`V1-0804`、`V1-0808`。

### 2.4 效果和外部发布

- 至少三场可比较、已绑定、指标口径稳定的运营数据，尚未形成有效效果信号。
- 外部平台自动录屏采集尚未做真实平台验收。
- 当前交付只生成本地交付包，没有确认向外部平台发布、接收回执、外部对象回读和实际曝光。

## 3. 需要但当前没有完整落地的流程

### 3.1 严格意义上的设计缺口

这些不是单纯“测试没跑”，而是尚未形成完整的客户可执行流程：

1. **客户首次接入**：环境配置、麦兔账号绑定、测试房间绑定、外部服务配置和能力校验向导。
2. **人工交接闭环**：分配人工任务、上传操作结果、记录回读差异、返工和关闭任务。
3. **历史素材治理**：批量补分类、补权利状态、去重、路径修复、重新扫描和权利到期影响分析。
4. **外部交付与对账**：外部交付适配器、回执、超时对账、外部对象身份和撤回影响分析。
5. **持续运营数据接入**：Webhook/API/定时拉取、增量导入、迟到数据、补数、删除和指标口径变更。
6. **真实客户验收反馈闭环**：客户确认、问题记录、体验指标、版本反馈和下一轮范围回流。

### 3.2 长期设计已有方向，但当前没有可执行产品流程

1. **统一 Shot/ShotList**：当前已有最小 ShotList 产物，但直播场景、视频 Clip 和时间轴之间的统一投影与镜头编辑尚未完整落地。
2. **排播与开播授权**：没有排播页面、冲突检查、`GoLiveAuthorization` 或正式开播 API；BuildPlan 永久保持 `go_live=false`。
3. **RoleStrategy、A/B、RoleEvaluation**：没有策略版本选择、实验分流、A/A、SRM、护栏、因果分析和角色效果评价流程。
4. **因果实验与可信效果闭环**：当前只支持描述性和关联性分析，没有预注册实验、曝光校验和受控策略变更。
5. **完整权利与组织管理**：没有多租户、细粒度权限、地域/渠道授权、到期策略和双人审批。
6. **生产级运行控制**：容量、SLO、灾备、长任务恢复、跨日任务治理和生产监控尚未形成完整运营流程。

## 4. 当前可用性判断

| 能力范围 | 当前判断 |
| --- | --- |
| 素材库、约束、选材、缺口 | 本地真实流程可用 |
| 录屏解析与模板 | 本地流程可用，真实客户录屏未确认 |
| 事实到剧本到场景 | 种子验收可用，真实业务输入未确认 |
| 麦兔场景、图层、BuildPlan | 可生成和人工交接，自动写入未确认 |
| 本地成片、剪辑、时间轴 | 本地真实产物已跑通 |
| 运营数据与归因 | 文件导入和描述性归因已跑通 |
| 知识链路与效果再生产 | 本地投影和草稿再生产已跑通，效果信号不足 |
| 正式外部发布、排播、开播 | 当前不提供 |
| A/B、RoleStrategy、RoleEvaluation | 当前不提供 |

因此，当前正确的产品表述是：**可以在本地完成从素材、内容、方案到成片和运营分析的可审阅闭环；真实麦兔自动写入、正式发布、排播开播和实验学习仍不应对外承诺。**
