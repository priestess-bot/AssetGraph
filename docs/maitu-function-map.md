# 麦兔功能地图与 AssetGraph 建模参考

记录时间：2026-07-09

本文基于当前账号登录 `https://live2.maituai.com/Login` 后的麦兔界面实测整理。用途是指导 AssetGraph 后续做素材整理、麦兔槽位建模、Browser use 操作计划和数字人直播间自动化搭建。

> 操作原则：本文只记录功能和字段，不代表需要自动点击提交。Browser use 执行麦兔时应默认只做明确任务指定的操作，避免误保存、误删除、误开播。

---

## 1. 麦兔整体主菜单

左侧主菜单当前可见 5 个模块：

1. 首页
2. 数字分身
3. 素材管理
4. 商品库
5. 直播记录

顶部还有：

- 语言切换：简体中文
- 平台版本切换：当前看到淘宝版；历史项目里也有京东平台直播间
- 用户/账户入口

## 2. 首页

首页主要功能：

### 2.1 创建直播间

入口：

```text
首页 → 创建直播间 → 立即创建
```

弹窗字段：

| 字段 | 说明 |
|---|---|
| 直播间名称 | 必填 |
| 创建方式 | 智能生成直播间 / 回放生成直播间 / 空白直播间 |
| 直播模式 | 实时渲染 / 预生成模式 |
| 高级设置 | 可从已有直播间复制直播互动配置 |

创建方式：

1. 智能生成直播间：上传商品，自动生成脚本。
2. 回放生成直播间：复用直播回放，更像真人。
3. 空白直播间：从空白开始搭建自定义。

直播模式：

1. 实时渲染
2. 预生成模式

高级设置：

- 支持从已有直播间复制直播互动配置。
- 当前示例中可以选择已有直播间 `38995 品酒大师`。

### 2.2 创建数字分身

首页也有快速入口：

```text
创建数字分身
数字分身 = 模特 + 声音
```

该入口最终对应数字分身模块里的“创建分身”。

### 2.3 直播间列表

首页直播间列表支持：

- 全部
- 普通直播间
- 回放直播间
- 状态筛选

直播间卡片信息示例：

| 字段 | 示例 |
|---|---|
| 直播间名称 | 品酒大师 |
| 直播间 ID | 38995 |
| 模式 | 实时渲染 |
| 状态 | 可开播 |
| 创建/更新时间 | 07/08 10:39:46 |

## 3. 数字分身模块

入口：

```text
左侧菜单 → 数字分身
```

页面页签：

1. 数字分身
2. 模特
3. 声音

核心逻辑：

```text
数字分身 = 模特 + 声音
```

因此 AssetGraph 应把麦兔“数字分身”一级素材类型内部拆成三类对象：

1. 模特：数字人形象/动作/口型基础。
2. 音色：声音克隆/声音训练结果。
3. 数字分身成品：模特 + 音色组合后的可用主播。

---

### 3.1 数字分身页签

功能：

```text
创建分身
```

创建分身表单字段：

| 字段 | 说明 |
|---|---|
| 名称 | 必填 |
| 选择模特 | 从已有模特中选择 |
| 选择声音 | 从已有声音中选择 |

当前账号可见示例：

- 明月
- 张裕定制形象260519

AssetGraph 对应建议：

```text
数字分身成品 = digital_human_avatar
关联字段：speaker_id + digital_human_image_id
```

本地已整理目录：

```text
D:/AssetGraph/素材/数字分身/数字分身成品
```

---

### 3.2 模特页签

入口：

```text
数字分身 → 模特 → 定制模特
```

页面标题：

```text
定制数字模特
```

表单字段：

| 字段 | 说明 |
|---|---|
| 模特名称 | 必填 |
| 绿幕选择 | 绿幕制作 / 非绿幕制作 |
| 模特类型 | 单片段 / 多片段 |
| 模特源视频 | 上传训练视频 |

绿幕选择：

- 绿幕制作
- 非绿幕制作

模特类型：

- 单片段
- 多片段

#### 单片段训练要求

页面显示：

```text
请上传竖版 9:16 视频，支持 MP4/MOV/WebM 格式，1080p、2k、4k 分辨率，文件大小不超过 15G
```

#### 多片段训练要求

页面显示：

```text
模特源视频：0/50
请上传竖版 9:16 视频，支持 MP4/MOV/WebM 格式，1080p、2k、4k 分辨率，文件大小不超过 5G
已上传0个视频；总时长：00:00:00 / 03:00:00
```

多片段规则：

| 项目 | 要求 |
|---|---|
| 视频数量 | 最多 50 个 |
| 总时长 | 最多 3 小时 |
| 单文件大小 | 不超过 5G |
| 格式 | MP4 / MOV / WebM |
| 比例 | 竖版 9:16 |
| 分辨率 | 1080p / 2k / 4k |

AssetGraph 本地目录：

```text
D:/AssetGraph/素材/数字分身/模特
```

当前示例：

```text
7717_Y26定制
8856_明月
```

### 3.3 声音页签

入口：

```text
数字分身 → 声音 → 定制声音
```

页面标题：

```text
定制数字声音
```

表单字段：

| 字段 | 说明 |
|---|---|
| 音频名称 | 必填 |
| 音频文件 | 必填 |
| 辅助音频 | 可选 |
| 语种 | 默认中文 |
| 文件封面 | 可选 |
| 服务协议 | 需要勾选 |

主音频要求：

```text
音频文件支持 mp3、wav、m4a
录制音频在 10-60 秒即可
```

辅助音频要求：

```text
音频文件支持 mp3、wav、m4a 格式
录制音频不能大于 8 秒，大小不超过 20MB
```

AssetGraph 本地目录：

```text
D:/AssetGraph/素材/数字分身/音色
```

当前示例：

```text
3760_Y26音色
4224_明月（五抖官旗）
```

详情页包含：

1. 商品卖点
2. 优惠价格
3. 参数信息
4. 图文详情

- 商品主图/预览
- 商品名称
- 商品ID
- 编辑按钮

当前商品详情中：

AssetGraph 建模建议：

```text
Product
├── platform_product_id
├── name
├── selling_points
├── promo_price
├── parameter_info
├── graphic_detail
└── product_image_asset
```

1. 顶部直播间信息区
2. 左侧商品列表/场景列表

## 8. 右侧直播配置区

右侧页签：

1. 直播脚本
2. 直播互动
3. 账号授权

---

### 8.1 直播脚本

当前空脚本时显示：

```text
请添加您的第一个脚本
当您添加脚本时，它将显示在此处
+ 添加文本
```

脚本内容是数字分身口播/直播流程的一部分。

AssetGraph 对应：

```text
Script
ScriptBlock
scene_id
text
order_num
```

---

### 8.2 直播互动

直播互动子页签：

1. 智能回复
2. 氛围互动
3. 智能切品
4. 商品弹链

#### 智能回复

可见字段：

- 开启回复：开关
- 回复方式：示例为“数字分身 + 弹幕”
- 回复范围：示例为“麦兔AI + 问答库”
- 回复时机：示例为“句末回复”
- 语音回复：示例为“正常字数”
- 回复频率：数字分身每 N 分钟最多互动 N 次
- 问答库：共 N 条
- 商品问答 / 场景问答
- 下载 / 上传问答库
- 添加问答项

AssetGraph 对应：

```text
InteractionConfig
QAItem
product_qa
scene_qa
reply_mode
reply_scope
reply_timing
reply_frequency
```

#### 氛围互动

可见分组：

- 新进直播间
- 新增关注
- 其他氛围触发项（页面下方还有更多，未全部展开）

每个分组通常包含：

- 数字分身互动开关
- 弹幕互动开关
- 触发条件：每 N 分钟，最多互动 N 次
- 回复话术
- 添加话术
- 话术条数上限，例如 1/10

示例话术：

```text
欢迎【用户昵称】，进入我们的直播间！
```

AssetGraph 对应：

```text
AtmosphereInteraction
trigger_type
human_reply_enabled
bullet_reply_enabled
frequency_minutes
max_times
scripts
```

#### 智能切品

可见字段：

- 开启设置：开关

作用：控制直播过程中是否自动切换商品/讲品。

#### 商品弹链

可见字段：

- 商品弹链：开关
- 商品讲解：开关

作用：控制商品链接弹出与商品讲解联动。

### 8.3 账号授权

字段：

## 10. AssetGraph 后续建模重点

### 10.1 麦兔素材类型

基于麦兔 UI，AssetGraph 应保留以下素材类型：

```text
数字分身
背景
装饰
视频
文本
模版
```

其中：

- `背景/装饰/视频/模版` 来自素材管理。
- `数字分身` 来自数字分身模块。
- `文本` 来自编辑器创建，不一定是素材管理里的文件。

本地目录当前应保持：

```text
D:/AssetGraph/素材/数字分身
D:/AssetGraph/素材/背景
D:/AssetGraph/素材/装饰
D:/AssetGraph/素材/视频
D:/AssetGraph/素材/模版
```

文本类可先存在数据库，不一定落地文件目录。

### 10.5 Browser use 操作计划注意事项

Browser use 在麦兔中执行时应遵循：

1. 不默认点击“正式开播”。
2. 不默认点击“删除”。
3. 不默认点击“保存”，除非当前任务明确要求保存。
4. 不改变数字人主播位置，除非用户明确要求。
5. 替换素材时优先使用麦兔原类型：背景、装饰、视频、模版、数字分身、文本。
6. 商品 PNG 贴片在麦兔中可能属于“装饰”，不要强行按商品图类型处理。
7. 转场视频在麦兔中属于“视频”，场景类型可以是“过渡”。
8. 文本分两类：画面文本图层和直播脚本文本，不能混淆。
9. 直播互动、账号授权、直播间设置属于配置，不是画面素材。
10. 场景/图层/槽位替换要保持原坐标、层级、尺寸和主播位置。

## 11. 对当前 AssetGraph 项目的直接影响

后续开发 AssetGraph 时，应优先补强：

1. 麦兔素材基础类型表：数字分身、背景、装饰、视频、文本、模版。
2. 数字分身三层模型：模特、音色、数字分身成品。
3. 场景类型字段：讲品、特写、问答、过渡。
4. 直播间编辑器图层模型：Canvas 图层、素材类型、坐标、尺寸、层级。
5. 商品库模型：商品 ID、商品名、卖点、价格、参数、图文详情、商品图。
6. 直播互动配置模型：智能回复、氛围互动、智能切品、商品弹链。
7. 直播间设置模型：全局话术、讲品设置、自定义昵称、读音修正、商品权重。
8. Browser use 操作计划要以麦兔 UI 的真实模块和类型为准。
