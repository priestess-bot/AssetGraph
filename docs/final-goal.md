# AssetGraph 最终目标：数字人直播视频多模态资产图谱

## 1. 一句话定位

AssetGraph 是一个面向麦兔软件与数字人直播业务的多模态视频资产管理与智能分析系统，用来集中存放数字人直播录屏、切片、脚本、字幕、封面、商品素材、麦兔场景素材、评论数据和复盘内容，并通过多模态理解、向量检索和知识图谱，把每一场数字人直播沉淀为可检索、可分析、可复用的内容资产。

更简洁地说：AssetGraph 是数字人直播的视频资产大脑。

## 2. 为什么不是通用素材库

AssetGraph 不以通用网盘、普通 DAM 或泛素材库为最终目标。它的第一业务场景是数字人直播视频资产，因此系统设计优先服务以下问题：

- 某场数字人直播有哪些完整素材？
- 直播里使用了哪个数字人形象、哪个音色、哪套脚本？
- 每个商品在哪些时间段被讲解？
- 哪些视频片段、话术、封面、商品素材可以复用？
- 哪些片段适合做短视频二创？
- 哪些片段存在口型不同步、卡顿、音频质量差、画面异常等问题？
- 哪些脚本块、商品卖点、数字人形象和互动反馈之间存在有效关系？

因此 AssetGraph 的业务中心不是孤立的 `Asset` 文件，而是：

```text
LiveSession + VideoSegment + DigitalHuman + VoiceProfile + Script + Product
```

同时，因为 AssetGraph 要服务麦兔软件，系统还必须记录素材在麦兔项目中的用途分类、场景、图层、槽位和替换策略。素材替换只是其中一个子能力：短期内 Agent 应能在已有麦兔直播间中保持原场景结构、图层位置和尺寸完成安全替换；长期目标是形成“素材库 + Browser-use 现场”的联合调度能力：素材库负责检索、推荐、蓝图和计划，Browser-use 负责读取真实页面现场、执行小步操作、截图验证和结果回写，最终从空白麦兔直播间开始生成、创建、搭建、校验并沉淀可开播直播间。

麦兔相关上下文包括：

```text
MaituProject + MaituScene + MaituLayer + MaterialSlot + ReplacementPolicy
```

## 3. 长期愿景

AssetGraph 致力于成为数字人直播业务的多模态资产图谱平台。它将直播录屏、视频切片、数字人形象、音色、脚本、商品、字幕、评论和复盘内容统一入库，并通过视频理解、语音转写、向量检索和知识图谱，构建可检索、可分析、可复用的数字人直播资产网络，服务于直播复盘、短视频二创、话术优化、素材推荐和 AI Agent 内容生产工作流。

## 4. 四个核心子系统

### 4.1 数字人直播资产库

负责统一存放和管理：

- 完整直播录屏
- 直播切片和高光片段
- 封面图、商品图、场景图
- 字幕、ASR 转写文本
- 直播脚本、脚本块、话术模板
- 评论、弹幕、互动数据
- 直播复盘报告
- 麦兔项目素材、场景素材、图层素材和可替换槽位
- 数字人形象素材
- 音色和口播音频素材

### 4.2 多模态解析系统

负责把视频素材转化为可理解的数据：

- 视频抽帧
- 镜头/段落切分
- ASR 语音转写
- 字幕对齐
- OCR
- 商品识别
- 数字人识别
- 场景识别
- 画面质量检测
- 音频质量检测
- 口型/音画同步检测

### 4.3 数字人直播知识图谱

负责沉淀关系：

- 数字人和直播的关系
- 音色和数字人的关系
- 商品和视频片段的关系
- 脚本块和视频片段的关系
- 评论互动和时间段的关系
- 直播、商品、项目、标签、复盘报告之间的关系

### 4.4 内容复用与生产助手

负责把沉淀资产用于生产：

- 按商品、话术、数字人、时间段查找视频片段
- 找相似片段、相似封面、相似脚本
- 自动生成直播复盘
- 自动推荐短视频切片
- 自动整理商品素材包
- 基于历史高效片段生成新脚本
- 为 AI Agent 提供素材检索和上下文调用能力
- 抽取用户选中的麦兔参考直播间，沉淀直播间 ID、平台、场景、图层、素材页签和脚本文本，形成可复用的 ReferenceRoomProfile
- 持续读取 Browser-use 现场状态，把当前登录态、URL、场景、图层、素材页签、文本框内容和截图回传给 AssetGraph，用于校准蓝图和安全 preflight
- 基于商品、脚本、数字人、音色、品牌素材和参考模板生成 LiveRoomBlueprint / SceneBlueprint / LayerBlueprint
- 将直播间蓝图转换为 BuildPlan，包含创建直播间、创建场景、插入素材图层、设置图层坐标/层级、添加脚本块、保存草稿等步骤
- 为麦兔直播间模板推荐可替换素材，并保持原场景/图层布局完成替换
- 根据麦兔槽位自动返回候选素材、匹配分和匹配原因，降低 Agent 拼接查询条件的复杂度
- 为麦兔项目/场景生成完整素材替换方案，记录每个槽位的选中素材和缺失素材
- 将替换方案转换为 Browser use 可理解的操作步骤，由 Browser use 实际操作麦兔软件完成直播间搭建/素材替换
- 接收 Browser use 执行结果回写，记录成功、失败、单槽位错误、截图素材和复盘摘要，让麦兔自动化从“给操作步骤”进入“可追踪执行闭环”
- 对 Browser use 失败结果进行分类，记录是否可重试和重试指令，并沉淀 `MT-RETRY-*` 重试任务，支持后续自动恢复或人工介入
- 将单个 `MT-RETRY-*` 重试任务转换为 Browser use 可理解的最小化重试步骤，只重试失败槽位并保持麦兔原有布局
- 接收 Browser use 重试结果回写，自动更新重试任务状态、重试次数、最近执行编号、截图和结果摘要，形成“失败-重试-回写-关闭”的恢复闭环
- 提供重试队列视图，让 Browser use 或 Agent 可以批量拉取 pending、retryable、未超过最大尝试次数的重试任务并持续处理
- 提供重试任务领取/释放机制，记录 `claimed_by`、`claimed_at`、`claim_expires_at`，避免多个 Browser use worker 重复执行同一个任务
- 提供过期领取回收机制，将超时的 `in_progress` 重试任务释放回 `pending`，避免 worker 崩溃后任务永久卡死
- 提供 worker 一站式取活入口，自动回收过期任务、领取下一条任务并返回 Browser use 操作计划，降低 worker 编排复杂度
- 文档化 Browser use retry worker 执行协议，明确取任务、执行最小化操作、成功回写、可恢复失败释放和不可恢复失败转人工的完整流程

## 5. 核心业务对象

### 5.1 LiveSession

一场数字人直播，是业务聚合根。它关联直播录屏、切片、数字人、音色、脚本、商品、评论和复盘结果。

### 5.2 VideoSegment

从完整直播录屏中切分出的片段。它应记录起止时间、字幕、讲解商品、脚本块、数字人、音色、质量分和复用分。

### 5.3 DigitalHuman

数字人形象资产。记录数字人名称、人设、风格、版本、供应商、适用品类和历史直播表现。

### 5.4 VoiceProfile

数字人直播使用的音色资产。记录音色名称、供应商、性别、风格、语速、情绪和适用品类。

### 5.5 Product

直播讲解的商品。记录商品名称、品牌、品类、卖点、痛点、关联视频片段和关联脚本块。

### 5.6 Script 与 ScriptBlock

直播脚本和结构化话术块。脚本块应支持开场、商品介绍、痛点引导、卖点讲解、价格机制、促单、互动、结尾等类型。

### 5.7 Maitu Material Context

麦兔素材上下文。记录素材在麦兔项目中的业务用途分类、场景名称、图层名称、图层位置、槽位名称和替换策略，确保 Agent 替换素材时不破坏直播间布局。槽位本身使用 `MT-SLOT-{YYYYMMDD}-{SEQ}` 编号，表示麦兔模板中的可替换位置。

### 5.8 InteractionEvent

评论、弹幕、点赞、点击、下单等互动事件。它们应能落到直播时间线或具体视频片段上，用于复盘和效果分析。

## 6. 第一阶段 MVP 闭环

第一版优先打通一条最小闭环：

```text
上传一场数字人直播录屏
  -> 生成 live_code
  -> 生成 asset_code
  -> 存储原视频
  -> 抽取音频
  -> ASR 转写
  -> 按时间切分 video_segments
  -> 关联数字人、音色、商品、脚本
  -> 支持按关键词/商品/时间段检索片段
```

第一阶段暂不追求完整自动化识别所有实体。允许人工录入或半自动标注数字人、音色、商品、脚本和片段边界，优先保证数据模型、编号体系和检索闭环正确。

## 7. 成功标准

### 7.1 短期成功标准

- 能创建数字人、音色、商品、脚本和直播场次。
- 能为直播录屏生成稳定编号并入库。
- 能创建视频片段并关联到直播、数字人、商品、脚本块。
- 能按 `live_code` 聚合查看一场直播的所有素材和片段。

### 7.2 中期成功标准

- 能对直播视频做 ASR 转写和基础片段切分。
- 能按商品、字幕关键词、脚本块、数字人检索视频片段。
- 能把文本和视觉 embedding 写入向量库，支持相似检索。
- 能把核心对象与关系写入 Neo4j，支持图谱查询。

### 7.3 长期成功标准

- 能自动产出直播复盘。
- 能推荐可二创短视频片段。
- 能沉淀高效话术和商品讲解模板。
- 能检测数字人口播质量、音画同步和异常片段。
- 能作为 AI Agent 的数字人直播素材大脑。
