## 1. 手册范围与能力边界

### 1.1 当前页面清单

| 页面 | 正式入口 | 主要用途 |
| --- | --- | --- |
| 业务概览 | `/console/` | 查看产出、运营反馈、资料覆盖和最近项目 |
| 素材库 | `/console/assets` | 导入素材、分类、使用状态、布局约束、分组、素材包、缺口和分析 |
| 直播模板 | `/console/templates` | 上传录屏、解析清洗、创建、发布和停用模板 |
| 知识库 | `/console/knowledge` | 管理商品事实、审核版本和登记事实来源 |
| 内容项目 | `/console/projects` | 从直播间目标组织简报、剧本、直播间、成片、交付和动态 |
| 运营分析 | `/console/operations` | 导入运营数据、补充内容关联、分析表现和设置指标 |
| 效果学习 | `/console/learning` | 沉淀候选规律、人工判断并用于新项目 |
| 直播间编辑器 | `/console/production/live-rooms` | 编辑场景、图层、话术和麦兔操作清单 |
| 成片编辑器 | `/console/production/videos` | 建立并编辑竖屏成片时间轴、查看渲染和下载产物 |
| 交付工作区 | `/console/production/releases` | 检查、查看审批入口、下载交付清单 JSON 和撤回 |

直播间、成片和交付通常从某个内容项目内进入，不在左侧一级导航单独展示。

### 1.2 可用性标记

| 标记 | 含义 |
| --- | --- |
| 本地可用 | 当前本地前后端和数据库可以完成操作 |
| 有条件可用 | 还需要指定数据、后台处理进程、外部账号或已验证能力 |
| 只读 | 页面可以查看，但不能在当前界面修改或执行 |
| 当前未提供 | 规划或后端可能存在相关能力，但当前正式前端没有入口 |

### 1.3 必须牢记的产品边界

1. 工作台默认可直接浏览，不应出现“运营控制台登录”或“访问凭据”页面。
2. 麦兔自动写入只针对空白、未开播的草稿房间；当前真实账号能力未验证时，应使用页面中的人工操作清单。
3. 正式开播、排播和开播授权在整个产品中全局禁用，没有可操作入口。
4. 交付页下载的是交付清单 JSON，其中只有媒体产物引用，不包含成片、封面等媒体文件，也不会自动发布到外部平台。
5. 运营分析是描述性或相关性复盘，不代表严格因果关系。
6. 保存剧本、直播间场景和成片时间轴会创建新版本，不应理解为直接覆盖历史版本。
7. `?demo=1` 只用于界面演示；演示任务、通知和概览不是生产数据。

### 1.4 可直接收藏的页面深链

| 目标 | 深链格式 |
| --- | --- |
| 指定素材 | `/console/assets?asset=<素材编号>` |
| 素材组 / 素材包 / 缺口 / 分析 | `/console/assets?tab={groups,packs,gaps,analysis}` |
| 指定模板 | `/console/templates?template=<模板编号>` |
| 录屏列表 | `/console/templates?view=sessions` |
| 指定事实 | `/console/knowledge?fact=<事实卡编号>`（仅能命中当前已加载的最新 50 张） |
| 指定事实来源 | `/console/knowledge?view=sources&source=<来源编号>` |
| 直接新建项目 | `/console/projects?create=1` |
| 项目子页 | `/console/projects?project=<项目编号>&tab={brief,script,live-room,video,delivery,activity}` |
| 运营待关联 / 指标设置 | `/console/operations?view={bindings,settings}` |
| 运营表现分析 | `/console/operations?view=attribution` |
| 指定直播间方案 | `/console/production/live-rooms?run=<方案编号>` |
| 指定成片方案 | `/console/production/videos?plan=<方案编号>` |
| 指定交付内容 | `/console/production/releases?release=<交付编号>` |

表格中 `{...}` 表示从括号内选择一个值，不要原样输入大括号。部分页签点击只改变当前页面状态，不会自动改写 URL；需要分享或收藏时使用上表格式。运营表现分析当前必须使用 `view=attribution`，不要使用 `view=analysis`。

## 2. 使用前准备

### 2.1 基本环境

1. 确认前端可访问：打开 `http://localhost:5190/console/`。
2. 确认后端可访问：打开 `http://localhost:8000/health`，应返回健康状态。
3. 推荐使用当前版本的 Chrome，并使用至少 `1440x900` 的桌面窗口进行编辑。
4. 素材、录屏、成片和运营文件都存放在本地服务中；不要在上传未完成时关闭页面。
5. 自动录屏解析、成片渲染、素材分析和麦兔写入分别依赖对应后台处理进程（下文简称 Worker）。按钮存在不代表处理进程已启动。

### 2.2 业务数据准备顺序

建议首次使用时按以下顺序准备数据：

1. 在素材库导入素材，补齐用途、使用状态和布局约束。
2. 在知识库登记来源和商品事实并完成审核。注意：当前项目创建向导不能选择事实，普通前端新建项目不会自动使用刚批准的事实。
3. 在直播模板中上传一份录屏，清洗后创建并发布模板。
4. 新建内容项目，填写直播间 ID、标题、生成目标并选择模板与素材。
5. 生成剧本、直播间方案或竖屏成片。
6. 完成交付后导入运营数据，并在效果学习中沉淀下一轮规律。

## 3. 全局操作

### G-01 切换工作区

可用性：本地可用。

1. 在左侧导航点击“业务概览、素材库、直播模板、知识库、内容项目、运营分析、效果学习”之一。
2. 当前页面会高亮显示。
3. 浏览器前进和后退可切换已访问路由。多个页面只在首次挂载时读取查询参数；同一路径只改变参数时，如果可见页签、详情或弹窗没有同步，按 `Ctrl+R`/`Command+R` 刷新当前 URL。
4. 窄屏时点击顶栏菜单图标打开导航，点击关闭图标或页面遮罩收起。

成功标志：页面主标题和左侧高亮项与所选工作区一致。

### G-02 使用全局搜索

可用性：当前正式 UI 不可用；只有 `?demo=1` 可以演示固定搜索结果。正式前端没有连接真实控制面数据的入口。

1. 点击顶栏“搜索素材、模板、知识或项目”。
2. 输入至少 2 个字符。
3. 等待搜索结果显示名称、业务类型、更新时间和状态。
4. 点击结果进入对应素材、模板、事实或项目。

成功标志：URL 进入相应 `/console/...` 深链，搜索面板自动关闭。

注意：普通“浏览工作区”状态下不会执行真实全局搜索。“没有匹配结果”此时不代表数据库中没有数据。

### G-03 查看任务中心

可用性：当前正式 UI 不可用；只有 `?demo=1` 可以查看固定演示任务。

1. 点击顶栏剪贴板图标“任务中心”。
2. 查看任务类型、标题、摘要、进度、状态和时间。
3. 点击任务进入对应项目动态或业务页面。
4. 再次点击图标，或点击抽屉右上角关闭按钮收起。

当前限制：任务中心不能领取、审批、取消或重试任务，只负责聚合和跳转。

### G-04 查看通知

可用性：当前正式 UI 不可用；只有 `?demo=1` 可以查看固定演示通知。

1. 点击顶栏铃铛图标“通知”。
2. 查看业务化标题、影响摘要、发生时间或累计次数。
3. 点击通知进入对应业务上下文。
4. 再次点击铃铛或抽屉关闭按钮收起。

当前限制：不能标记已读、忽略或批量处理通知。

### G-05 识别当前工作区状态

1. 右上角显示“当前工作区 / 浏览工作区”时，可以浏览和编辑普通业务页面。
2. 当前正式前端没有控制面令牌输入框，也没有从环境读取令牌的用户流程，因此普通用户无法切换到真实“已连接”状态。
3. 代码保留了内存令牌和“断开连接”兼容逻辑，但它不是当前可达的产品操作；刷新也不会建立连接。

当前界面没有录入账号、密码或令牌的登录表单，不要把右上角工作区状态当作登录入口。

### G-06 关闭弹窗、详情和放大预览

1. 对话框可点击右上角关闭按钮、取消按钮或按 `Esc` 关闭。
2. 右侧详情检查器使用“关闭详情”图标退出。
3. 图片放大预览可点击右上角关闭按钮或按 `Esc` 退出。
4. 不要把关闭弹窗当作统一的“放弃修改”。当前项目创建向导和事实来源弹窗会在本次页面会话中保留部分未提交输入；需要彻底丢弃时关闭后刷新页面，再重新进入。

### G-07 处理加载、空状态和页面错误

1. 如果首屏超过 8 秒仍停留在“正在载入直播内容工作台”，点击随后出现的“重新载入”。React 已启动后的普通“正在读取数据”没有自动重载按钮，应使用浏览器刷新。
2. 出现“当前工作区无法显示”时，可重新载入或返回业务概览。
3. 页面显示“暂时无法读取”时，先确认后端健康状态，再刷新页面。
4. 预期有数据却显示空状态时，不要立即判断数据已删除；先确认服务连接。概览、全局搜索、任务和通知在普通模式下本来就没有真实控制面连接。
5. 页面错误只展示业务影响与下一步，不会显示内部错误码或堆栈。

## 4. 业务概览

入口：`/console/`
可用性：普通正式 UI 只显示“业务概览数据尚未连接”；`?demo=1` 可查看固定演示概览。其它业务页面不受概览未连接影响。

### OV-01 切换统计周期

1. 点击“近 30 天”或“近 90 天”。
2. 查看指标、趋势、排行和最近项目随时间范围刷新。

成功标志：所选周期高亮，概览重新加载。

### OV-02 查看本周期指标

指标带展示内容项目、直播间方案、成片和已关联运营场次数量，以及相对上一周期的变化。该区域只读。

### OV-03 查看趋势并进入运营分析

1. 将鼠标移到趋势图日期上，读取当日运营场次、直播间方案和成片数量。
2. 点击“查看运营分析”。

成功标志：进入运营分析的“表现分析”视图。

### OV-04 查看活跃内容和资料覆盖

1. 在“近期活跃内容”中点击某个项目，进入该项目的“动态”。
2. 在“生产资料覆盖”中查看可用素材、已发布模板、已批准事实和场次关联率。

### OV-05 新建或继续项目

1. 点击右上角“新建项目”直接打开项目创建向导。
2. 点击“全部项目”进入项目列表。
3. 点击最近项目行进入该项目工作区。

## 5. 素材库

入口：`/console/assets`
页内视图：全部素材、素材组、素材包、素材缺口、素材分析。

### 5.1 全部素材

#### AS-01 导入一份素材

可用性：本地可用。

1. 点击右上角“导入素材”。
2. 选择图片、视频、音频、PDF 或 TXT 文件。当前一次只导入一份。
3. 检查自动带出的素材名称，按需要修改。
4. 复选一个或多个“素材用途”。同一素材可以同时承担多个用途。
5. 在“可用于”中选择：可用于麦兔、仅用于本地成片、仅供参考、不可用或待分类。
6. 点击“导入素材”。

成功标志：弹窗关闭，新素材出现在列表中，并可以打开预览。

失败处理：出现“素材没有导入”时检查文件格式和服务连接。元数据已经创建但文件上传失败时，列表中可能留下没有预览的记录，需要后续治理。

#### AS-02 搜索、筛选和切换视图

1. 在“搜索素材名称”输入名称或原文件名的一部分。
2. 使用“全部媒体”筛选图片、视频、音频、文档、字体或其它类型。
3. 使用“全部用途”筛选背景、商品展示、数字人、标题、文案、装饰、视频、音色、音乐或音效。
4. 点击网格图标或列表图标切换视图。

成功标志：结果数量和素材列表即时变化。

#### AS-03 预览素材

1. 图片卡片以完整内容优先显示缩略图。
2. 视频卡片默认显示第一帧；鼠标悬停时播放低清短预览，移开后回到首帧。
3. 单击图片或 GIF 打开右侧详情，再点击详情预览可居中放大。
4. 视频详情提供完整播放器。
5. 音频、文档和当前不支持的格式显示类型占位，不代表文件已丢失。

#### AS-04 单选和多选素材

1. 单击一份素材：选中并打开右侧详情。
2. 再次单击唯一选中的素材：取消选择并关闭详情。
3. 按住 Windows/Linux 的 `Ctrl` 或 macOS 的 `Command`，再依次点击其它素材进行多选。
4. 选中至少两份后，页面显示批量操作栏。

注意：不按组合键点击下一份素材会替换当前选择，而不是追加选择。

#### AS-05 批量加入已有素材组

前置条件：至少选择两份素材，并且已经存在素材组。

1. 点击批量栏“加入分组”。
2. 从下拉框选择已有素材组。
3. 点击“确认加入”。

成功标志：素材被追加到所选组，已有成员不会被移除。

禁用原因会直接显示：没有素材组时要求先新建；未选择具体素材组时“确认加入”不可用。

#### AS-06 用当前多选素材新建素材组

1. 多选至少两份素材。
2. 点击“加入分组”，再点击“新建素材组”。
3. 填写素材组名称；说明可选。
4. 检查页面列出的当前成员。
5. 点击“创建素材组”。

成功标志：新组创建完成，当前选中素材成为首批成员。

#### AS-07 批量追加素材用途

1. 多选至少两份素材。
2. 点击“追加用途”。
3. 选择要追加的用途。
4. 点击“确认追加”。

成功标志：所选素材保留原用途，并新增这一用途。

### 5.2 素材详情

#### AS-08 修改基本信息

1. 单击素材打开右侧详情。
2. 进入“基本信息”。
3. 选择媒体类型。
4. 选择“可用于”的执行范围。
5. 点击用途按钮添加或取消多个业务用途。
6. 点击“保存基本信息”。

成功标志：素材卡片的类型、用途或执行范围刷新。

当前限制：详情中不能修改素材名称，也不能删除素材。

#### AS-09 设置素材使用状态

1. 进入详情的“使用状态”。
2. 选择待确认、已批准、限制使用或已撤销。
3. 填写至少 3 个字符的“使用依据或限制”。
4. 点击“保存使用状态”。

成功标志：状态徽标更新。只有已批准的零散素材会出现在新项目的可用素材列表中。

#### AS-10 设置位置和大小约束

1. 进入详情的“布局约束”。
2. 设置左侧、顶部、宽度、高度，数值范围为 `0-1`。
3. 观察 9:16 画布中的位置预览。
4. 按需要启用“保持原始宽高比”。
5. 点击“保存约束”。

数值解释：`0.10` 表示画布尺寸的 10%。为避免整体越界，应确保“左侧 + 宽度 <= 1”且“顶部 + 高度 <= 1”。

#### AS-11 设置图层和桌面关系

1. 在布局约束中选择“自动、始终置顶、始终置底”之一。
2. 商品需要放在背景桌面上时，启用“商品需摆放在背景桌面上，并位于背景上方”。
3. 点击“保存约束”。

成功标志：系统保存新的约束配置版本；后续方案生成会把这些关系作为硬约束。

### 5.3 素材组

#### AS-12 在素材组页创建分组

1. 点击“素材组”。
2. 填写分组名称。
3. 至少勾选一份素材。
4. 点击“创建分组”。

成功标志：右侧已有分组列表出现新组。相同素材可以重复加入其它分组。

#### AS-13 删除素材组

1. 在已有分组中找到目标组。
2. 点击垃圾桶图标“删除分组”。

结果：分组立即从当前列表移除，组内素材本身不会被删除。

注意：当前没有二次确认，也不能重命名分组、编辑说明或从已有组移除单个成员。

### 5.4 素材包

#### AS-14 创建素材包

## 6. 直播模板

入口：`/console/templates`
页内视图：模板库、录屏与解析。

### TP-01 搜索和筛选模板

1. 在模板库输入模板名称。
2. 使用“全部、已发布、草稿、已停用”筛选状态。
3. 查看每张卡片的内容就绪度、布局可信度和构建能力。

说明：项目创建只列出已发布模板；“仅供参考”的外部录屏模板不会被当成可执行麦兔布局。

### TP-02 查看模板详情

1. 点击模板卡片。
2. 在右侧查看来源视频、内容结构、时间范围和使用边界。
3. 检查三个维度：内容是否可用、布局是验证布局还是近似参考、是否可直接构建。
4. 点击“关闭详情”返回列表。

### TP-03 从录屏创建模板：上传

1. 点击“从录屏创建模板”。
2. 填写来源直播间 ID。
3. 填写来源直播间名称。
4. 选择 MP4、MOV、MKV 或 WebM 录屏。
5. 点击“上传并解析”。

成功标志：上传进度到达完成并进入“解析内容”。三个输入缺一时按钮不可用。

### TP-04 从录屏创建模板：解析

1. 等待语音转写、画面文字、场景结构和关键画面产生结果。
2. 页面每约 3 秒刷新一次录屏状态。
3. 有时间线结果或录屏完成后，点击“清洗解析结果”。

当前限制：该步骤没有在当前页面提供单项重试按钮。

### TP-05 从录屏创建模板：清洗文字

1. 页面默认勾选全部语音片段。
2. 取消不应进入模板的片段。
3. 直接修改错字、金额或敏感信息。
4. 点击“审核模板”。

注意：即使没有文字或取消全部片段，也能继续；提交前应人工确认至少保留了有价值的内容。

### TP-06 从录屏创建模板：审核并创建草稿

1. 检查自动生成的模板名称并按需修改。
2. 填写适用内容类型；留空会按通用直播保存。
3. 检查来源直播间、时长、纳入文字数、布局使用方式和构建方式。
4. 点击“创建模板草稿”。

成功标志：向导关闭，模板库出现草稿。一个模板固定只绑定这一份录屏所属的单一来源直播间。

### TP-07 发布或停用模板

1. 打开草稿模板详情，点击“发布模板”。
2. 发布成功后，该模板可在新建项目时选择。
3. 对未停用模板点击“停用模板”，可将其移出后续选择。

注意：停用立即执行，没有二次确认；已停用模板不能在当前界面恢复。当前也不能编辑模板名称、内容结构或版本。

### TP-08 查看历史录屏

1. 点击“录屏与解析”。
2. 在左侧选择录屏。
3. 在右侧播放视频，并按时间查看语音文字。

当前限制：不能从历史录屏继续清洗创建模板，也不能在此重试解析、切片、下载、删除或管理自动采集直播间。

## 7. 知识库

入口：`/console/knowledge`
页内视图：商品事实、事实来源。

### KB-01 搜索和筛选商品事实

1. 在“商品事实”页签输入商品名或事实卡名称。

3. 卡片展示商品名、第一条已核验事实、事实数量和版本数量。

范围限制：当前页面只加载按创建时间倒序排列的最近 50 张事实卡，搜索和状态筛选也只作用于这 50 张。旧事实即使刚创建新版本或刚批准，也可能仍不在列表中；搜不到不代表数据已删除。

### KB-02 新建商品事实卡

1. 点击“新建事实卡”。
2. 必填事实卡名称、商品名称、商品定位。
3. 在“已核验事实”中至少填写一条；多条内容建议一行一条，也可用逗号分隔。
4. 可选填写品牌、品类、适用场景和合规备注。
5. 点击“创建事实卡”。

成功标志：新草稿出现在事实卡列表中。草稿必须批准后才能用于生成。

边界：这里的“可用于生成”只表示事实版本状态合格；当前项目创建向导没有事实选择器，不能把刚批准的事实直接关联到新项目。

### KB-03 查看事实详情和使用情况

1. 点击事实卡打开右侧详情。
2. 查看最新版本、商品信息、已核验事实和适用场景。
3. 在“被哪些内容使用”查看当前版本的引用对象、时间和状态。
4. 点击“关闭详情”返回列表。

当前限制：不能切换或对比旧版本；合规备注不在详情中展示；使用记录没有直接跳转。

### KB-04 批准事实版本

前置条件：最新版本状态为草稿。

1. 打开事实详情。
2. 点击“批准版本”。
3. 关闭详情后重新打开，确认状态变为已批准。

成功标志：版本具备被后续内容生成使用的状态资格。它仍需由后台预先关联到项目；当前项目向导不能完成这项关联。

### KB-05 驳回事实版本

1. 打开草稿事实详情。
2. 填写“驳回原因”。
3. 点击“驳回版本”。
4. 关闭详情并重新打开确认状态。

说明：驳回版本不会用于生成。当前审核失败没有独立错误提示，因此需要重新打开复核结果。

### KB-06 创建事实新版本

1. 打开任意事实详情，点击“创建新版本”。
2. 表单会复制最新版本内容。
3. 修改商品信息、事实、场景或合规备注。
4. 填写必填的“本次修改说明”。
5. 点击“创建新版本”。

成功标志：创建新的草稿版本，原批准版本不会被原地覆盖。

注意：当前版本表单中的事实卡名称修改不会通过现有保存接口生效。

### KB-07 添加事实来源

1. 点击“事实来源”。
2. 点击“添加来源”。
3. 填写来源标题。
4. 选择文档、网页、平台导出或人工确认。
5. 可选填写来源地址。
6. 粘贴支持事实的原文摘录。
7. 点击“保存来源”。

成功标志：来源以草稿状态出现在列表中。

### KB-08 批准或查看事实来源

1. 草稿来源右侧显示“批准”，点击后等待列表刷新，并确认状态变为“已批准”。
2. 已非草稿且填写了来源地址时，点击“查看原文”在新标签页打开。
3. 指定来源深链会将该来源排在列表前面并高亮。

当前限制：来源列表没有搜索、筛选、编辑、驳回、撤回或删除；草稿优先显示批准按钮，不能从该行直接打开原文。批准请求失败时页面没有独立错误提示；状态未变化时刷新并检查服务，不要误判为已经批准。

### KB-09 当前知识关联边界

1. 当前新建事实卡表单不能选择已登记来源，因此无法在前端建立“事实卡引用来源”的关系。
2. 当前项目创建向导也不能选择事实卡；普通前端新建项目不会自动使用知识库中刚批准的事实。
3. 当前知识库前端没有内容规则、事实声明、完整来源链或知识图谱重建入口。
4. 这些能力即使存在后端接口，也不应当作当前页面已上线功能。

## 8. 内容项目

入口：`/console/projects`
项目工作区：简报、剧本、直播间、成片、交付、动态。

### PR-01 搜索和筛选项目

1. 输入项目名称或生成目标。
2. 使用“全部、草稿、进行中、已停用”筛选。
3. 点击项目行进入简报。

注意：某些“已确认”项目只会在“全部”中出现。

### PR-02 新建项目：基本信息

1. 点击“新建项目”，确认向导停在“基本信息”且字段为空。
2. 填写直播间 ID，最长 128 个字符。
3. 填写直播间标题，最长 255 个字符。
4. 填写至少 10 个字的生成目标，说明面向谁、讲清什么和希望观众完成什么动作。
5. 点击“下一步”。

连续创建提醒：当前向导关闭或创建成功后可能保留上一次的步骤、表单、模板和素材选择。如果重新打开时不是空白“基本信息”，立即关闭并刷新 `/console/projects?create=1`，不要直接提交旧选择。

### PR-03 新建项目：创意补充

1. 可选填写主题和目标观众。
2. 设置预计时长，范围 `1-1440` 分钟，默认 60 分钟。
3. 可选填写故事线。
4. 可选填写详细设计，包括场景、陈列、互动、话术和禁用内容。
5. 点击“下一步”。

### PR-04 新建项目：选择参考模板

1. 在“主参考”中最多选择一个已发布模板；再次点击可取消。
2. 在“次要参考”中最多选择 5 个模板。
3. 主模板不会同时保留在次要模板中。
4. 没有模板也可以继续。
5. 点击“下一步”。

注意：选择第 6 个次要模板时当前界面不会提示，只会保持原有 5 个。

### PR-05 新建项目：选择素材

1. 在左侧独立复选素材组。
2. 在右侧独立复选零散素材。
3. 检查底部汇总的模板、素材组和零散素材数量。
4. 点击“创建项目”。

成功标志：进入新项目“简报”。项目允许不选模板和素材先创建。

说明：零散素材只显示使用状态已批准且未标记不可用的素材；素材组当前不会预先过滤组内每份素材的状态。

### PR-06 整理生成简报

1. 在项目“简报”查看生成目标和项目参考摘要。
2. 首次点击“整理生成简报”。该动作会先确认并固定项目输入，再解析生成结构化简报；这里的“项目输入已确认”不等于下一步的“简报已确认”。
3. 检查目标直播间、主题、观众、时长、故事线和详细设计。
4. 如果操作报错，先刷新项目：项目输入确认可能已经成功、但简报解析失败。确认当前状态后再决定是否重试或新建项目。
5. 如果页面列出阻塞问题，当前页面无法原地回答或修订，也不能再次整理；只能新建输入完整的项目，或由受控后台流程调用尚未暴露的修订能力。

成功标志：页面出现结构化简报和待确认状态。

### PR-07 确认简报并生成内容

1. 仅在没有阻塞问题时点击“确认简报”。
2. 状态变为已确认后，点击“生成剧本与场景”。
3. 等待生成完成，再点击“查看剧本”。

成功标志：剧本页出现多个话术块，直播间方案创建所需的节目结构和镜头数据已生成。

当前实现使用本地确定性规则生成简报、剧本和场景，适合验证结构化生产流程；不要把它表述为已经通过真实客户输入验收的大模型创作质量。

### PR-08 编辑剧本

1. 点击“剧本”。
2. 逐块修改话术文本。
3. 查看每块预计时长和事实引用数量。
4. 点击“保存新版本”。

成功标志：剧本保存为新项目修订，历史版本不会被直接覆盖。

### PR-09 回看已有项目的事实依据

前置条件：该项目已经由受控后台流程预先关联事实；普通前端新建项目不会自动具备这些引用。

1. 在话术块下找到“事实依据”。
2. 点击某条引用。
3. 引用目标位于当前加载范围时，系统进入对应事实卡详情，或进入事实来源并高亮来源。

当前限制：事实卡跳转复用知识库最新 50 张列表；较旧事实不在该范围时会退回知识库首页，需要通过后台记录查询事实编号。

### PR-10 进入直播间、成片和交付

1. 点击“直播间”创建或编辑直播间方案。
2. 点击“成片”创建或编辑竖屏成片。
3. 点击“交付”处理当前项目的交付候选。
4. 标签右侧圆点表示该类产物是否已存在。

### PR-11 查看项目动态

1. 点击“动态”。
2. 按时间查看版本、生成、直播间、成片、交付和运营关联等关键变化。
3. 任务中心和通知中的项目类事项也会跳转到这里。

当前限制：动态只读，不能直接在时间线中处理任务。

### PR-12 当前项目编辑边界

1. 项目创建后，当前界面不能重新编辑基本信息、模板选择和素材选择。
2. 创建向导不能选择知识事实或内容规则；普通前端新建项目不会使用刚在知识库批准的事实。只有后端已经预关联的项目才会在生成阶段使用满足状态要求的事实。
3. 结构化故事简报、节目结构和镜头清单会保存，但当前没有独立查看或编辑页面。
4. 简报页只能显示阻塞问题，不能在原地回答问题或修订解析字段。
5. 剧本页只能修改已有话术文本，不能新增、删除或排序话术块，也不能修改类型、预计时长和事实引用。
6. 当前界面不能复制、停用或删除项目。
7. 如果初始输入必须更改，只能新建项目或等待后续项目修订入口。

注意：新建向导当前显示“创建后仍可自由修改”，但上述编辑入口尚未实现。实际操作应以本节边界为准。

## 9. 直播间配置与麦兔草稿

推荐入口：内容项目 -> “直播间”；独立深链：`/console/production/live-rooms?run=<方案>`。

### LR-01 创建直播间方案

前置条件：项目已经完成“整理简报 -> 确认简报 -> 生成剧本与场景”。

1. 在项目中点击“直播间”。
2. 如果还没有方案，选择内容项目。
3. 检查或调整自动带出的直播间 ID 和标题。
4. 复选至少一个素材组或一份零散素材。
5. 点击“生成直播间方案”。

成功标志：进入三栏直播间编辑器，并生成场景蓝图、图层和麦兔操作清单。

失败常见原因：项目还没有生成镜头结构、房间 ID/标题为空、没有选择任何素材，或选材无法满足必需角色。

### LR-02 选择场景和图层

1. 在左侧点击场景。
2. 展开的场景下会显示图层，并按较高图层顺序优先展示。
3. 点击图层，中央画布和右侧属性同步选中。
4. 也可以直接点击画布中的素材图层完成选择。

### LR-03 调整场景顺序；新增和删除暂不可保存

1. 选中一个已有场景。
2. 使用左下角上移或下移按钮调整顺序。
3. 点击底部“保存场景”。

可用范围：只改变现有场景顺序可以保存。第一个场景不能上移，最后一个不能下移。

当前限制：界面虽然显示“新增场景”和“删除场景”，但后端当前要求来源镜头必须全部保留且各出现一次；新增临时镜头或删除来源镜头后保存必然失败。不要使用这两个控件；误操作后刷新页面以丢弃浏览器内草稿，再重新编辑。

### LR-04 编辑场景名称和话术

1. 选中场景但不要选图层。
2. 在右侧“属性”修改场景名称。
3. 在中央画布下方修改“当前场景话术”。
4. 完成后点击底部“保存场景”。

### LR-05 重建同用途图层；自由增删暂不可用

后端要求每个场景最终保留来源镜头的全部必需画面用途，而且每种用途恰好出现一次。最稳妥的操作是不改变原有用途集合，只更换素材或调整属性。

需要重建某一层时：

1. 记录该图层原来的画面用途。
2. 选中图层并点击“移除图层”。
3. 点击左侧或右侧“添加图层”。新图层默认使用素材库第一份素材；素材库为空时不会新增。
4. 立即把新图层改回刚才记录的同一用途，并选择合适素材。
5. 确认其它必需用途没有缺失或重复，再点击“保存场景”。

当前限制：不能新增额外用途、删除必需用途或任意改变用途集合；这些操作都会在保存时被后端拒绝，页面只显示概括性失败。误操作且无法恢复时刷新页面，重新从原版本开始。

### LR-06 更换图层素材；用途修改受限

1. 选中图层。
2. 在“使用素材”选择其它素材。
3. 保持原“画面用途”不变；只有在最终仍完整保留原必需用途集合、且每种用途恰好一次时才可调整用途。
4. 点击“保存场景”。

注意：素材出现在下拉框中不代表一定满足当前镜头的必需角色和使用范围；不符合时后端会拒绝保存。

### LR-07 调整图层位置、尺寸和顺序

1. 选中图层。
2. 修改左侧、顶部、宽度和高度：左侧、顶部范围为 `0-1`，宽度和高度必须大于 `0` 且不超过 `1`。
3. 修改图层顺序，范围 `0-100`，值越大越靠上。
4. 观察中央 9:16 画布实时更新。
5. 点击“保存场景”。

联合边界：必须同时满足“左侧 + 宽度 <= 1”和“顶部 + 高度 <= 1”。当前输入框只限制单个数值，不会提前阻止整体越界；越界会在保存时失败。

当前界面通过数值调整，不支持直接拖拽或缩放画布图层。

### LR-08 保存直播间场景

1. 完成场景、图层或话术修改后点击底部“保存场景”。
2. 等待“场景修改已保存为新版本”。

说明：所有编辑先保存在当前浏览器状态；离开页面前必须保存。保存会创建新的不可变方案版本。

深链限制：保存后页面会显示新版本，但地址栏中的 `?run=` 仍指向旧方案编号。此时刷新会重新打开旧版本，看起来像修改丢失；不要继续收藏旧地址。当前前端没有展示新版本编号的入口，需要从项目“直播间”重新进入并核对版本，或由后台查询新编号。

### LR-09 查看麦兔能力边界

1. 点击右侧“操作清单”或底部“查看操作清单”。
2. 查看每项草稿能力是“可自动完成、需人工完成、暂不支持”。
3. 查看按顺序排列的麦兔搭建步骤。

“查看操作清单”只切换视图，不会下载、派发或完成一项人工任务。

### LR-10 使用人工操作清单

可用性：本地只读，适用于自动写入不可用时。

1. 按清单顺序核对直播间与标题。
2. 在麦兔中人工创建场景、放置素材、填写话术和保存草稿。
3. 不点击正式开播。

当前界面尚未提供人工任务分配、结果上传、差异复核和关闭任务的完整交接闭环。

### LR-11 请求自动写入麦兔草稿

可用性：有条件可用。

前端按钮同时满足以下条件才可点击：

1. 方案状态可使用。
2. 草稿写入尚未请求。
3. 当前麦兔能力矩阵允许自动草稿。
4. 用户已勾选“目标是空白未开播草稿”。

点击“写入麦兔草稿”只会登记执行请求，不证明 Worker、登录账号或目标房间当前可用。请求真正执行还要求麦兔 Worker 正在运行、账号已登录、目标仍是空白未开播草稿，并通过现场预检；条件不足时可能长期等待 Worker 或转为需要人工处理。

### LR-12 同步草稿结果

1. 当状态为已请求、运行中、需要核对或失败时，点击“同步草稿结果”。
2. 检查底部状态和操作清单是否更新。

当前限制：执行或同步请求失败没有独立错误提示。自动能力未验证时按钮会显示“自动写入暂不可用”，这是正确的降级状态。

### LR-13 当前直播间方案边界

1. 独立路由会自动打开匹配的第一份方案，没有方案选择器。
2. 当前界面不能新建第二份方案、复制方案或切换同项目的多份方案。
3. 创建面板尚未接入素材包、素材缺口、角色覆盖和项目级约束覆盖。
4. 外部录屏模板只提供内容节奏或近似视觉参考，不会直接变成麦兔图层布局。
5. 方案被阻断时，当前编辑器没有完整展示具体门禁结果，只会给出概括性失败提示。
6. 正式开播始终不在麦兔搭建计划中。

## 10. 竖屏成片与时间轴

推荐入口：内容项目 -> “成片”；独立深链：`/console/production/videos?plan=<成片方案>`。

### VD-01 新建成片制作

前置条件：来源项目已经完成简报整理与确认，并生成结构化故事简报、剧本和镜头清单。当前页面仍会列出内容链不完整的项目，选择后会在创建时失败。

1. 选择“从内容项目”或“从直播间方案”。
2. 选择具体项目或直播间方案。
3. 选择目标时长：30、45、55、60 或 90 秒。
4. 可选选择背景音乐。
5. 可选复选最多 6 份可本地剪辑的视频素材。
6. 点击“建立初始时间轴”。

成功标志：进入成片编辑器并出现初始镜头。

失败处理：返回项目“简报”，完成“整理生成简报 -> 确认简报 -> 生成剧本与场景”，再重新建立时间轴。

素材规则：视频列表只显示媒体类型为视频且可用于本地成片的素材。音乐列表只按“音频类型 + 背景音乐用途”展示，尚未预先过滤执行范围和本地文件完整性；实际选择的音乐还必须可用于本地成片，并具备有效本地文件和校验和，否则后端会拒绝创建。

Worker 竞争提醒：初始时间轴创建后并不会为编辑锁定，正在运行的视频 Worker 可能立即领取任务。若字段已经变为只读，不要反复点击；等待初版完成或失败，再按 VD-10 创建编辑副本。编辑副本会先保持可编辑，保存后才进入制作。

### VD-02 预览当前镜头或成片

1. 点击时间轴中的画面或字幕片段。
2. 最终成片尚未生成时，播放器显示当前镜头的素材，并叠加对应标题和字幕。
3. 最终成片已经生成时，播放器始终播放整条成片并使用封面作为海报；选择镜头只更新叠加的标题和字幕，不会自动跳到该镜头时间位置。

### VD-03 更换画面素材

前置条件：当前成片状态为等待制作且尚未被 Worker 领取，或已经按 VD-10 创建编辑副本。

1. 在右侧“镜头”中选择画面素材。
2. 选择“沿用原画面”或其它本地视频素材。
3. 点击底部“保存时间轴”。

### VD-04 调整镜头时长、速度和转场

1. 选择镜头。
2. 设置时长，范围 `0.25-120` 秒。
3. 选择播放速度：`0.75x、1x、1.25x、1.5x`。
4. 选择直接切换、淡入淡出或淡出。
5. 确认全部镜头总时长位于 `30-120` 秒。
6. 保存时间轴。

### VD-05 编辑标题和字幕

1. 选择镜头。
2. 修改标题文字和字幕。
3. 选择字幕位于画面底部或中部。
4. 在时间轴顶部选择紧凑、标准或大字字幕样式。
5. 保存时间轴。

### VD-06 调整人声音量

1. 选择镜头。
2. 修改“人声音量”，范围 `-30` 到 `12`。
3. 保存时间轴。

### VD-07 调整镜头顺序

1. 选择镜头。
2. 点击“前移”或“后移”。
3. 检查画面轨和字幕轨同步变化。
4. 保存时间轴。

第一个镜头不能前移，最后一个不能后移。

### VD-08 设置海报帧

1. 在时间轴顶部填写“海报帧”秒数。
2. 数值必须大于等于 `0` 且严格小于当前总时长，不能等于片尾时刻。
3. 保存时间轴。

### VD-09 保存时间轴并开始制作

1. 检查镜头、字幕、音频、海报帧和字幕样式。
2. 点击“保存时间轴”。
3. 等待“时间轴已保存为新版本”。

结果：系统创建新的时间轴修订，并由视频 Worker 处理渲染。页面会自动轮询等待制作或正在渲染的方案。

注意：首次创建的初始时间轴可能在编辑前就被 Worker 领取；此时应等待初版结束并创建编辑副本，不把无法编辑误判为保存失效。

### VD-10 编辑已完成或失败的成片

1. 已完成或失败的成片需要修改内容时，点击“创建编辑副本”。
2. 进入新的等待制作分支后再编辑和保存。
3. 如果制作状态为失败但不需要改内容，在“制作进度”中点击“重新制作”。

说明：已完成成片保持不可变，后续修改必须使用编辑副本。

深链限制：创建编辑副本会生成新的成片方案编号，但地址栏中的 `?plan=` 仍指向原方案。刷新会重新打开原成片；不要把旧地址当作编辑副本。应从项目“成片”重新进入并核对最新方案，或由后台查询新编号。

### VD-11 查看进度、质检和下载产物

1. 点击右侧“制作进度”。
2. 查看准备素材、生成音频、生成字幕、合成画面、检查成片和整理产物等阶段。
3. 查看画面尺寸、时长、黑屏和静音诊断。
4. 制作完成后下载成片、封面和镜头总览。

### VD-12 当前时间轴边界

1. 当前界面不能新增、删除或拆分镜头，只能修改已有镜头并调整顺序。
2. 剪辑、字幕和音频三个工具图标当前只是工具栏标识，点击不会切换独立模式。
3. 当前没有成片方案列表或“再新建一份成片”入口；存在方案时会自动打开第一份匹配方案。
4. 制作失败时页面不展示完整的阶段错误原因，只提供重新制作入口。
5. 当前不是完整非线性剪辑软件，不支持多层视频轨、关键帧或自由拖拽裁剪。

## 11. 交付工作区

推荐入口：内容项目 -> “交付”；独立深链：`/console/production/releases?release=<交付内容>`。

可用性：有条件可用。必须先存在交付候选；当前直播间和成片页面没有“创建交付候选”的前端入口，因此新项目通常需要既有数据或通过受控后台流程先建立候选。项目摘要没有交付引用时，“交付”页只显示空状态。

### DL-01 选择交付内容

1. 当项目有多份交付内容时，在左侧选择竖屏成片或直播间草稿。
2. 右侧查看创建时间、固定产物数、确认记录和交付记录。

### DL-02 运行交付检查

前置条件：交付状态为候选。

1. 点击“运行交付检查”。
2. 检查交付产物、素材使用范围、内容来源和其它质量门禁。

成功标志：全部必要检查通过后进入等待人工批准状态。

失败处理：该候选固定了创建时的交付清单，修改素材、直播间或成片不会刷新它。先补齐使用依据、制作质量或草稿回读，再由受控后台流程创建新候选，并对新候选运行检查。

### DL-03 批准交付

可用性：当前正式前端无法完成。状态为等待批准时会显示表单，但提交依赖控制面运营令牌；正式 UI 没有连接或录入该令牌的实现。

1. 填写至少 3 个字符的确认说明。
2. 点击“批准交付”。

预期结果：授权配置完整时状态会变为已批准，并出现交付清单操作。

当前默认入口不能满足上述授权条件。不要把已显示的审批表单理解为当前用户可以完成审批。

### DL-04 退回修改

可用性：当前正式前端无法完成，与批准使用相同且不可达的控制面授权。

1. 填写至少 3 个字符的退回依据。
2. 点击“退回修改”。
3. 返回直播间或成片页完成修订。
4. 当前前端不能从修订结果直接创建新候选，需要由受控后台流程建立后再回到交付页。

### DL-05 记录交付并下载交付清单 JSON

1. 填写至少 2 个字符的接收方或使用场景。
2. 点击“记录并生成交付包”。
3. 点击“下载当前交付包”下载交付清单 JSON。

成功标志：交付历史新增一条目标和处理状态记录。

说明：界面沿用“交付包”按钮文案，但当前下载内容只是完整交付记录的 JSON，媒体部分只有引用。它不包含成片、封面或其它媒体文件；这些文件仍需在成片页分别下载。该动作不调用外部发布平台，也不代表内容已经产生外部曝光。

### DL-06 查看交付历史

在“交付记录”查看接收方、创建时间、完成时间和处理状态。该区域只读。

### DL-07 撤回交付内容

1. 点击“撤回”。
2. 填写至少 3 个字符的撤回原因。
3. 点击“确认撤回”。

结果：交付内容保留在历史中，但不能再次批准或交付。

注意：撤回是终止操作。页面会先展开原因表单，再由“确认撤回”执行；点击确认后不会再出现第三次确认弹窗。

### DL-08 当前交付边界

1. 当前页面不能从直播间或成片直接创建交付候选。
2. 项目内交付页在存在多份全局交付内容时可能显示其它项目的内容，操作前必须核对载体和创建时间。
3. 当前没有第三方发布、回执、超时对账或外部对象回读。
4. 下载入口与“记录并生成交付包”是两个独立动作，下载 JSON 不等于已经登记一次交付。

## 12. 运营分析

入口：`/console/operations`
页内视图：数据导入、待关联、表现分析、指标设置。

### OP-01 下载运营数据模板

1. 点击页面右上角“下载导入模板”或数据导入区“下载 Excel 模板”。
2. 按模板填写直播场次、时间、外部场次 ID、内容关联和指标值。
3. 保留模板字段名、时区和单位，不要只填写展示名称。

### OP-02 上传并检查文件

1. 进入“数据导入”。
2. 选择 CSV 或 Excel 文件。
3. 点击“检查文件”。
4. 等待导入预览；检查前不会写入正式数据。

当前部署配置面向不超过 5 MB、5000 行的本地文件。

### OP-03 阅读导入预览

1. 查看场次数、可直接导入行、需补充关联行、需修复行和重复行。
2. 逐行检查直播场次、时间、内容关联、指标和检查结果。
3. 对格式错误、缺失字段、单位或时区问题，回到源文件修改后重新选择并检查。

当前限制：预览表不能直接编辑错误单元格。

### OP-04 确认入库

1. 确认可导入数量大于 0。
2. 点击“确认导入 N 行”。

成功标志：批次显示“已入库”。有效但缺少内容关联的行会进入“待关联”；无效行和重复行不会作为新数据导入。

### OP-05 补充场次内容关联

1. 点击“待关联”。标签上的数字表示待处理场次数。
2. 在每张场次卡中选择本场实际使用的内容项目、直播间方案或成片。
3. 点击“确认关联”。

成功标志：该卡从待关联列表消失，场次可以进入内容表现分析。

### OP-06 选择指标并重新计算

1. 点击“表现分析”。
2. 选择分析指标。
3. 切换指标后立即点击“重新计算”，等待更新时间变化后再读取维度结果。
4. 当前数据范围固定为全部已导入场次。
5. 查看更新时间，确认报告属于刚选择的指标。页面顶部“样本”当前显示全部导入场次数，不是包含所选指标的有效样本数，不能用它判断该指标覆盖率。

按钮禁用通常表示没有指标、没有已导入场次或计算正在进行。

注意：当前页面在所选指标还没有报告时可能暂时回退显示另一指标的旧维度结果，因此切换指标后不能跳过重新计算和更新时间核对。

### OP-07 切换分析维度

1. 依次点击“按场次、按内容段、按模板、按素材”。
2. 查看数值排行、样本量和证据说明。
3. 某个维度为空时，继续导入并关联更多场次后重新计算。

注意：页面明确展示的是关联趋势，不得据此声称某个素材或模板造成了业务结果。

### OP-08 新建业务指标

可用性：有条件可用，数据库中必须已经由部署或受控后台流程预置至少一份数据合同。当前正式页面不能创建数据合同或数据来源。

1. 点击“指标设置”。
2. 点击“新建指标”。
3. 填写指标名称和业务含义。
4. 填写单位。
5. 选择求和、计数、平均值、最大值或期末值。
6. 选择后台已经预置的数据来源。
7. 点击“保存指标”。

成功标志：新指标出现在列表中并处于使用状态。指标编码由系统生成，不需要用户填写。

### OP-09 当前运营设置边界

1. 当前页面不能编辑、停用或删除已有指标。
2. 当前数据范围选择器只有“全部已导入场次”。
3. 当前没有外部系统接口或自动回调的定时增量拉取、迟到数据和补数管理界面。
4. 当前分析不是因果实验，也没有外部曝光对账。

## 13. 效果学习

入口：`/console/learning`
页内视图：规律库、项目建议。

### LE-01 建立候选规律

前置条件：运营分析中已经有表现分析报告，并有来源内容项目。

1. 在“规律库”点击“建立候选规律”。
2. 选择依据的表现分析。
3. 选择来源内容项目。
4. 填写观察到的规律。
5. 点击“保存候选规律”。

成功标志：规律以“待判断”状态出现在规律库中。

来源核对：当前页面允许任意组合表现报告和内容项目，系统不会验证所选项目是否真正出现在该报告的场次中。保存前必须人工核对报告场次的内容关联；否则“查看来源”只会跳到手工选择的项目，不能证明它是数据来源。

### LE-02 评估候选规律

1. 查看观察指标、有效样本、证据强度和可复用范围。
2. 查看它是否可用于后续内容建议，以及样本、口径或证据方面的限制。
3. 点击“查看来源”回到原内容项目复核。

### LE-03 接受规律

1. 对待判断规律点击“接受规律”。
2. 等待状态变为“已接受”。

结果：接受后会解锁“用于新项目”的人工再生产，但不会自动修改任何项目。当前页面创建的候选固定为“描述性观察”，即使接受也不会贡献项目建议中的历史表现分；只有后台已有且满足资格的关联性证据才可能参与评分。

### LE-04 忽略规律

1. 对待判断规律点击“忽略”。
2. 填写为什么不采用。
3. 点击“确认忽略”。

成功标志：状态变为“已忽略”，并保留原因。

### LE-05 将已接受规律用于新项目

1. 对已接受规律点击“用于新项目”。
2. 填写“这次准备验证什么”。
3. 点击“创建项目草稿”。

成功标志：系统创建新项目并自动跳转。虽然按钮文案是“创建项目草稿”，实际结果是一个已确认简报、并已生成剧本、节目结构和镜头链的新项目；后续生产版本仍是不可执行状态，需人工复核后继续制作。

继承规则：系统整体保留来源项目的参考模板、主题、故事、详细设计、内容段落和首个生产版本的素材快照，并记录本次变化假设。当前不能逐项选择保留、替换或排除哪些内容。

### LE-06 查看项目建议

1. 点击“项目建议”。
2. 选择内容项目。
3. 查看模板和素材候选的综合分、内容匹配、约束适配、历史表现和推荐理由。
4. 不满足硬约束的候选会明确标记。
5. 点击“回到项目选择”返回项目。

说明：建议只辅助人工判断，不会自动替换项目选择。

### LE-07 正确理解证据

1. “描述性观察”只说明本次样本中看到的表现。
2. “有关联迹象”也不等于因果结论。
3. 当前页面建立的候选始终是描述性观察，不论是否接受，都不会贡献项目建议中的历史表现分。
4. 只有后台已经存在、证据等级为关联性且满足样本、指标口径、状态等资格的规律，才可能参与推荐；它仍不代表因果结论。

### LE-08 当前学习边界

1. 当前没有 A/B 分流、A/A、SRM、实验护栏或因果评估页面。
2. 当前没有规律搜索、筛选、编辑、过期或版本比较。
3. 项目建议页面不能一键把某个候选应用到已有项目。
4. 再生产时不能逐项选择继承哪些模板、素材或内容，也不能在提交前编辑生成的新项目信息。

## 14. 推荐端到端工作流

### WF-A 从素材和录屏生成直播间方案

1. 素材库：导入素材，设置媒体类型、用途、可用于范围和使用状态。
2. 素材库：为关键素材设置位置、尺寸、层级和桌面关系。
3. 素材库：创建素材组；素材包和缺口目前只做管理，不参与方案创建。
4. 知识库（可选、独立管理）：创建并批准商品事实。普通前端新建项目不能关联这些事实；只有后台已经预关联事实的项目才会在生成中使用。
5. 直播模板：上传单一来源录屏，等待解析，清洗文字，创建草稿并发布。
6. 内容项目：填写直播间 ID、标题、生成目标，选择一个主模板、最多 5 个次模板以及素材。
7. 项目简报：整理、确认并生成剧本与场景。
8. 项目剧本：检查话术并保存修订；项目已有后台预关联事实时，再检查事实引用。
9. 项目直播间：生成方案，重排或编辑已有场景、图层和话术，保存新版本；不要使用当前无法保存的场景新增/删除。
10. 麦兔：自动能力不可用时按人工清单搭建；能力已验证时仅向空白未开播草稿请求写入并同步结果。
11. 如果受控后台流程已经建立交付候选：在项目交付中运行检查。批准环节当前正式前端不可完成；由受控后台批准后，再下载交付清单 JSON。成片、封面等媒体文件仍需在成片页分别下载。

### WF-B 从内容项目生成竖屏成片

1. 完成 WF-A 的素材、项目简报和剧本步骤；事实只适用于后台已预关联的项目。
2. 在项目“成片”选择内容项目或直播间方案作为来源。
3. 选择目标时长、可选背景音乐和最多 6 份视频素材。
4. 建立初始时间轴。
5. 如果 Worker 已经领取初始时间轴，等待初版结束并创建编辑副本。
6. 调整镜头素材、顺序、时长、速度、转场、标题、字幕和音量。
7. 设置海报帧和字幕大小，保存时间轴。
8. 在“制作进度”查看渲染和质检。
9. 下载成片、封面和镜头总览。
10. 需要修改已完成成片时，先创建编辑副本。
11. 如果受控后台流程已经建立交付候选：在交付页运行检查。批准环节当前正式前端不可完成；由受控后台批准后，再下载交付清单 JSON。媒体文件仍从成片页分别下载。

### WF-C 从运营数据形成下一轮项目

1. 在运营分析下载模板并填写场次、内容关联和指标。
2. 上传文件，检查错误和重复行，确认有效数据入库。
3. 在“待关联”补齐无法自动识别的内容关系。
4. 在“表现分析”选择指标，重新计算并查看四个维度。
5. 在效果学习建立候选规律。
6. 回看来源项目，人工接受或忽略规律。
7. 对已接受规律填写变化假设，创建已确认且已生成内容链的新项目。当前页面创建的描述性规律只用于这次人工再生产，不会进入推荐评分。
8. 返回素材、模板和项目流程继续制作下一版本。

## 15. 常见按钮禁用、提交失败和阻断原因

| 页面 / 操作 | 表现与常见原因 | 处理方法 |
| --- | --- | --- |
| 导入素材 | 未选择文件或素材名称为空 | 选择文件并填写名称 |
| 保存使用状态 | 使用依据少于 3 个字符 | 补充明确的授权或限制说明 |
| 素材批量栏 | 只选了 0-1 份素材 | 按住 `Ctrl`/`Command` 至少选择两份 |
| 确认加入素材组 | 没有已有组，或未选择具体组 | 新建组或从下拉框选组 |
| 创建素材组 | 名称为空或没有成员 | 填写名称并选择素材 |
| 保存素材包 | 名称为空或没有成员 | 填写名称并至少勾选一份素材 |
| 标记缺口已解决 | 没有选择替代素材 | 先选择同用途候选素材 |
| 上传并解析 | 缺直播间 ID、名称或录屏文件 | 补齐三个输入 |
| 清洗解析结果 | 录屏尚未完成且没有时间线 | 等待解析 Worker 产出结果 |
| 创建事实卡 | 缺名称、商品、定位或已核验事实 | 补齐必填内容 |
| 驳回事实版本 | 驳回原因为空 | 填写驳回依据 |
| 项目下一步 | ID、标题或目标不符合校验 | 根据字段提示补齐 |
| 确认简报 | 存在阻塞问题 | 当前页不能修订；新建输入完整的项目，或由受控后台流程修订 |
| 生成直播间方案 | 缺项目、房间 ID、标题或素材时按钮禁用 | 补齐页面可见输入并选择素材 |
| 生成直播间方案 | 缺剧本/镜头时提交失败；缺必需角色时结果可能被阻断 | 先完成项目内容生成，并检查素材用途与执行范围 |
| 保存直播间场景 | 请求进行中时按钮禁用；场景集合、必需用途或素材不合规时提交失败 | 不增删来源场景，保持原必需用途集合且每种用途恰好一次，并检查素材状态 |
| 写入麦兔草稿 | 能力未验证、未确认空白草稿、状态不允许 | 使用人工清单，或完成能力和目标房间预检 |
| 成片素材复选 | 已达到 6 份 | 取消一份后再选择 |
| 成片编辑字段 | 当前方案不是等待制作，或已被 Worker 领取 | 等待当前制作结束，再创建编辑副本 |
| 保存时间轴 | 当前方案不可编辑或正在保存 | 等待当前制作/保存完成；需要修改时创建编辑副本 |
| 确认导入 | 没有可导入行 | 修复源文件并重新检查 |
| 确认关联 | 未选择实际内容 | 选择项目、直播间方案或成片 |
| 重新计算 | 没有指标或场次 | 先导入并关联数据 |
| 保存指标 | 名称/含义为空或没有数据来源 | 补齐字段；数据合同需由部署或后台预置，当前页不能创建 |
| 保存候选规律 | 未选报告/项目或说明为空 | 补齐三个输入 |
| 生成交付包 | 未批准或接收方不足 2 个字符 | 当前前端不能完成批准；只对后台已批准的既有内容填写目标并操作 |
| 确认撤回 | 原因少于 3 个字符 | 补充撤回原因 |

## 16. 当前界面未提供的操作

以下能力不要按照本手册推断为已经上线：

1. 素材重命名、素材删除、素材组重命名、组内成员移除。

4. 模板内容或布局编辑、版本比较和停用后恢复。
5. 在事实卡表单中绑定来源、知识规则/声明管理和知识图谱操作。
6. 编辑项目基本信息、重选模板/素材、复制或停用项目。
7. 项目级素材约束覆盖及把覆盖提升回素材库全局配置。
8. 直播间多方案选择/复制、画布拖拽、完整人工交接任务闭环。
9. 可保存的直播间场景新增/删除；当前只能重排并编辑已有来源场景。
10. 自由新增、删除或改变直播间图层用途；当前必须保持来源场景的必需用途集合不变。

14. 规律一键应用到已有项目、A/B 实验、角色策略和因果评估。
15. 外部平台自动发布、排播、开播授权和正式开播。

## 17. 常见问题排查

### 页面白屏或打不开

1. 访问 `http://localhost:8000/health` 确认后端。
2. 重新访问 `http://localhost:5190/console/`，不要使用已退役的 `/maitu/` 或 `/live-research/`。
3. 点击页面的“重新载入”，或执行浏览器强制刷新。
4. 若只有某个工作区失败，使用“返回业务概览”后重新进入。

### 素材没有预览

1. 确认素材是图片或视频；音频和文档当前使用占位。
2. 等待首帧或缩略图缓存生成。
3. 打开素材详情检查原文件是否能加载。
4. 新导入记录一直无预览时，可能是文件上传失败留下的元数据记录。

### 页面显示空列表但预期有数据

1. 确认当前不是服务未连接导致的空状态。
2. 清空搜索词和状态筛选。
3. 检查是否进入了正确页签。
4. 刷新页面后重新查询。
5. 概览、全局搜索、任务和通知在当前正式 UI 中没有控制面连接入口，普通模式不会请求真实数据；只有 `?demo=1` 可查看固定演示内容。普通业务列表主要依赖后端和数据库。

### 操作后状态没有变化

1. 等待请求完成，不要连续点击。
2. 关闭右侧详情后重新打开。
3. 刷新页面确认后端状态。
4. 查看页面是否显示“没有保存、没有完成、需要处理”等反馈。
5. 录屏解析、成片制作和麦兔执行还需要相应 Worker。

### 麦兔自动写入一直不可用

这是当前可接受的安全降级。当前静态能力矩阵会让自动写入按钮保持禁用；单独启动 Worker、登录麦兔账号或准备空白房间不会解锁按钮。只有后续把经验证的能力结果接入矩阵后，按钮才可能满足 LR-11 的前端启用门槛；请求发出后仍需 Worker、账号和目标房间现场预检。在此之前使用“麦兔操作清单”，不要绕过门禁，也不要尝试正式开播。

## 18. 状态与字段速查

### 18.1 素材使用状态

| 状态 | 含义 |
| --- | --- |
| 待确认 | 尚未确认授权或用途，不进入可执行选材 |
| 已批准 | 可以按执行范围进入项目和生成 |
| 限制使用 | 有明确限制，当前新项目零散选材不使用 |
| 已撤销 | 不应继续用于新生产 |

### 18.2 素材执行范围

| 范围 | 含义 |
| --- | --- |
| 可用于麦兔 | 已绑定或可以进入麦兔草稿构建 |
| 仅用于本地成片 | 可参与本地视频时间轴和渲染 |
| 仅供参考 | 可以用于理解或设计参考，不直接执行 |
| 不可用 | 不能参与生成 |
| 待分类 | 需要先确认能力边界 |

### 18.3 模板三个维度

| 维度 | 操作判断 |
| --- | --- |
| 内容 | 是否已经清洗并可用于节目结构和话术参考 |
| 布局 | 是麦兔验证布局、近似视觉参考，还是没有布局信息 |
| 构建 | 是否包含足够信息直接进入构建；外部录屏通常仅供参考 |

### 18.4 归一化画布数值

直播间和素材约束中的位置、尺寸均按 `0-1` 表示画布比例。例如：左侧 `0.10`、顶部 `0.20`、宽度 `0.50`、高度 `0.30`，表示素材从画布左侧 10%、顶部 20% 的位置开始，占画布宽 50%、高 30%。
