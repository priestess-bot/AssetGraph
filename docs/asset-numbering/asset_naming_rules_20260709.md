## 1. 编号原则

继续兼容现有 AssetGraph 后端编号：

```text
AG-{asset_type}-{YYYYMMDD}-{SEQ}
```

其中 `asset_type` 使用文件形态：

| asset_type | 含义 | 示例 |
|---|---|---|
| IMG | 图片、GIF、封面图 | `AG-IMG-20260709-000001` |
| VID | 视频 | `AG-VID-20260709-000001` |
| AUD | 音频 | `AG-AUD-20260709-000001` |
| DOC | 文档 | 暂不用于素材文件夹媒体素材 |
| OTH | 其他 | 兜底 |

## 2. 麦兔真实类型单独保留

麦兔真实类型不塞进 `asset_code`，而是保留为目录和清单字段：

```text
maitu_type = 数字分身 / 背景 / 装饰 / 视频 / 文本 / 模版
```

## 3. 文件命名格式

建议重命名后的文件名：

```text
{asset_code}_{可读标题}{扩展名}
```

示例：

```text
AG-IMG-20260709-000001_37200_张裕定制形象260519.png
AG-VID-20260709-000001_pro-6765.mp4
AG-AUD-20260709-000001_Y26音色_试听音频.mp3
```

## 4. 保留追溯字段

重命名清单中保留：

- `asset_code`
- `asset_type`
- `maitu_type`
- `maitu_subtype`
- `file_role`
- `original_relative_path`
- `new_relative_path`
- `original_filename`
- `new_filename`
- `title`
- `maitu_material_id_guess`
- `size_bytes`

## 5. 特殊规则

1. `*_cover` 这类无标准扩展名文件经检测实际是 PNG，预案中统一补成 `.png`。
2. 麦兔素材 ID 如 `37262_背景-3.png` 里的 `37262` 不丢弃，保留在清单字段 `maitu_material_id_guess` 中；文件名里可读标题中默认去掉开头 ID，避免名称过长。
3. 商品 PNG 贴片仍按 `maitu_type=装饰` 处理。
4. 转场素材仍按 `maitu_type=视频` 处理。
5. 数字分身成品、模特、音色按 `maitu_subtype` 区分。
