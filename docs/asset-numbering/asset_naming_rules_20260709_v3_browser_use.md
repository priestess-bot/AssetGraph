## 设计目标

这版规则不再受限于旧的 `AG-IMG/VID/AUD` 文件形态编号，而是优先服务三个目标：

1. **素材库管理**：一眼能看出素材属于麦兔哪个类型、什么用途、对应哪个商品/数字人。
2. **Browser use 选素材**：文件名和清单字段直接包含 `麦兔类型 + 用途 + 主体 + 角色`，方便自动筛选。
3. **麦兔直播间搭建**：命名直接贴合麦兔 UI：数字分身、背景、装饰、视频、文本、模版；场景中商品贴片仍归装饰，转场仍归视频。

## 编号体系

### 1. 普通麦兔素材

普通素材一个文件就是一个素材对象：

```text
MT-{TYPE}-{SEQ}
```

| 前缀 | 麦兔类型 | 示例 |
|---|---|---|
| MT-BG | 背景 | `MT-BG-0001` |
| MT-DEC | 装饰 | `MT-DEC-0001` |
| MT-VID | 视频 | `MT-VID-0001` |
| MT-TPL | 模版 | `MT-TPL-0001` |
| MT-TXT | 文本 | `MT-TXT-0001` |

### 2. 数字分身素材

数字分身是组合型对象，采用“实体编号 + 文件编号”：

```text
DH-{ENTITY}-{SEQ}-F{FILE_SEQ}
```

| 前缀 | 含义 | 示例 |
|---|---|---|
| DH-MDL | 模特 | `DH-MDL-0001-F001` |
| DH-VOI | 音色 | `DH-VOI-0001-F001` |
| DH-AVT | 数字分身成品 | `DH-AVT-0001-F001` |

这样一个模特可以拥有多个训练素材、封面、预览视频，但仍然能看出它们属于同一个实体。

## 文件名格式

```text
{file_code}_{麦兔类型或子类型}_{用途/主体/角色}{扩展名}
```

示例：

```text
MT-VID-0001_视频_商品讲解视频_品酒大师PRO.mp4
MT-DEC-0007_装饰_商品贴片_品酒大师MASTER.png
MT-BG-0001_背景_直播背景_背景-3.png
DH-MDL-0001-F012_模特_7717_Y26定制_品酒大师PRO_训练素材.mov
DH-VOI-0001-F002_音色_3760_Y26音色_训练音频.mp3
DH-AVT-0001-F001_数字分身成品_37200_张裕定制形象260519_成品封面.png
```
