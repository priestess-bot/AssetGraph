## 编号规则

继续兼容后端已有编号格式：

```text
AG-{asset_type}-{YYYYMMDD}-{SEQ}
```

`asset_type` 是文件形态，不是麦兔业务类型：

| asset_type | 含义 | 本次数量 |
|---|---|---:|
| IMG | 图片/GIF/封面 | 71 |

## 文件名规则

```text
{asset_code}_{短标题}{扩展名}
```

短标题规则：

1. 数字分身素材优先保留“模特/音色/成品名 + 角色”。
2. 训练素材优先简化为产品短名，例如 `品酒大师PRO_训练素材`。
3. 超长商品名不完整塞进文件名，商品 ID 和原名保存在清单里。
4. `*_cover` 无标准扩展名文件经检测为 PNG，预案中补为 `.png`。
5. 完全重复素材不直接删除，只在清单中标注 `duplicate_group` 和 `dedupe_suggestion`。
